# 🎨 Figma Project: Studentpartout Job Posting Interface

This repository contains the design concept and promotional interface for the **Studentpartout** platform — a service aimed at connecting young talents with businesses through modern, user-friendly job postings.

## 📌 Overview

This project demonstrates a **responsive landing page design** that promotes a job posting package for new customers. It is optimized for both desktop and mobile platforms, with a clear call-to-action and persuasive customer testimonials.

### ✅ Key Features

- 🔥 Special new customer discount (40%)
- 🧾 Job posting package (3 listings, 30-day duration, etc.)
- 📨 Email delivery of job applicants
- 📌 Support for top-positioning and publication to partner job portals
- 📱 Fully responsive layout (desktop + mobile views)
- 💬 Testimonials from satisfied candidates
- 📍 Elegant and accessible UI layout
